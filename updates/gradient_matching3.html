Disclaimer

The following interactive plots were generated in collaboration with the the integrated copilot agent in vs code. The agent used the code devoloped last week by myself to generate the plots, but has made them interactive as apears here.

This was done in order to easily observe the effect of training the model on different data points throughout the past. The graphs then plot the actual data vs what the model predicts for the given data points.

Interactive Plots

Use the slider to choose the month through which the Python gradient-matching model is trained. The upper plot tests the fitted coefficients on later elevations; the lower plot compares the training spline derivative with the derivative fitted by the ODE.
